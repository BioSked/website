A small patch on top of 4.5, released to all instances on 20 May 2026.

### 💎 Improvements

- **Contract terms** use clearer labels.
- **Creating and editing assignments** no longer requires the publish privilege, matching Momentum Classic.
- **List view exports** use the same file layout as before: a Name column, standard date and hours formatting, no stray columns.

### 🪲 Fixes

- Overlapping time-off is no longer counted twice.
- Notifications reach the right recipients.
- Some filter combinations no longer return an error.
- Staff lists never abbreviate names, whatever the display settings.
